## 环境与试验边界

使用真实 macOS Chrome `152.0.7977.76`，本地 `127.0.0.1:18765`；
解释器为锁定依赖临时环境 CPython `3.14.6`，`dependencies_locked=true`、
`timezone_available=true`。使用当前项目页面/HTTP/JobManager 源码及原真实 RUN-002 的临时副本，
浏览快照始终为 `SWIVD2-RUN-20260901-002 / 20260901`。

更新部分显式替换作业层的目标日期选择与数据 worker，不调用 provider。
测试固定时钟为 `2026-09-02T10:00:00+08:00`，固定目标为 `20260901`，用于核对截止原因的页面表达；
它不是对验收当天最新数据的判定。测试进程禁止 outbound connect/connect_ex/getaddrinfo，不加载真实 token。

受控 worker 先停在 INDUSTRY_DATA，再由临时控制文件分别触发 DAILY_BASIC_EMPTY 或
ALREADY_UP_TO_DATE。它检验真实浏览器、HTTP、作业进度与恢复交互，
**不是新版真实 Tushare 数据更新、发布或历史快照生成的 E2E 证明**。
原离线/宿主测试负责数据计算、发布事务及轮询重试等其他已登记层，本轮没有重复执行整套。
